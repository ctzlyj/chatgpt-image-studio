# 本地工作台与网页图片 API 的组合

## 数据流

```text
React 工作台 / 本地 /v1 图片 API
  → 本机访问及会话鉴权
  → 工作台任务规划（计数 / 每行一项 / 每图一项）
  → SQLite 保存幂等批次和各图片任务
  → 单账号有界队列（默认串行，待处理最多 50 项）
  → 网页适配器：参考图上传 → prepare → conversation
  → SSE 会话回执 → 查询图片文件 → 下载
  → 本地 PNG + 结果元数据 → 页面轮询 / API 回包
```

## 模块

- `studio/planner.py`：移植原自定义生图规划与提示词规则；不混入原系统商业功能。
- `studio/upstream/backend.py`：源项目网页协议适配，固定 ChatGPT 域名，可配置会话模型，不接受任意接口地址。
- `studio/provider.py`：把网页会话转换为生成结果，关闭连接，保守处理拒绝、超时和未知结果。
- `studio/service.py`：独立图片任务、幂等编号、逐项错误、排队取消。
- `studio/store.py`：SQLite 和本地图片，参考图内容去重、图片解析校验。
- `studio/settings.py`：当前用户加密配置，凭证不回显。
- `studio/app.py`：本地 API、图片 API、受保护的文件服务、前端静态页面。
- `web/`：自定义生图工作台、历史、图片修改、大图、连接设置。

## 与原系统的边界

保留计数生成、逐行队列、共享参考图、逐图修改与通用参考图、条件画布提示词、继续修改保真规则、历史、下载。网页上游不具备原服务商 API 的全部参数能力，因此不展示虚假的 seed 或严格分辨率控制；目标像素仅出现在完整提示词预览中。

不引入原详情页平台的详情整套编排、跨境平台文案、商户计费、ERP 鉴权、腾讯云存储、多人租户或 Electron 桌面壳。此项目独立运行，不改变两份源项目。

## 失败与恢复

- 同一 `client_id` / `Idempotency-Key` 和相同任务内容只接收一次；已接受后切换工具或断线不触发再次提交。
- 单项失败继续处理后续任务；API 不以部分图片冒充全部成功。
- 取消只作用于尚未开始的任务；不谎称网页中的生成已经被取消。
- 重启标记 queued/running 为 interrupted；原始请求、任务与图片仍保留，不自动重放。
- 网页操作结果不明，先由用户核对网页和历史；手动载入要求不自动发起新请求。
- 当网页接口变化时，应先验证原始请求参数与回执。不能仅改对外模型名称宣称适配新模型。

## 验收边界

本地单元与接口测试使用注入的离线图片提供方；网页适配器协议测试使用模拟 HTTP 传输，真实地经过移植后的网页代码。浏览器测试与生产服务隔离，不使用生产凭证。

只有使用有效的用户账号从网页链路取得图片，才能另行标记在线生图验收完成。页面可打开、连接检查成功、模型列表显示新名称均不足以证明该项。
