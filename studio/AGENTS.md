# 号池与本地数据维护

- 号池、来源服务器凭证和导入回执在现有加密配置中原子保存。升级先验证旧账号仅迁移一次、本地 API 密钥不轮换、SQLite 历史和图片不变。
- 对外用独立账号编号关联任务，不把登录凭证放进任务表、接口响应、浏览器持久化存储或报错。会话 JSON 导入只提取凭证，账号展示信息由授权刷新获取。
- 新任务轮询账号租约，同时限制全局与单号并发。取消、失败和关闭都必须释放租约；不得把未知结果切换账号重试。
- 账号刷新与生成互斥。上游限流/失效状态不被另一个并发成功或手工额度注释清除；需有效刷新或更换凭证后再使用。
- 远程导入只读所选来源；不跟随管理接口重定向，修改来源地址不继承旧密钥。逐项回执持久化，重启标记中断而非重放，重复导入依靠凭证去重。
- 修改相关行为运行 `tests/test_accounts.py`、`tests/test_account_sources.py` 和浏览器号池测试；用隔离的合成账号验证多账号和远程协议，不把模拟通过表述为真实远端验收。
